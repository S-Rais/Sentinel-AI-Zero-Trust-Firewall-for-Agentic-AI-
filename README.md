# Sentinel-AI-Zero-Trust-Firewall-for-Agentic-AI-
Sentinel AI sits between users and LLM agents and stops attacks before they reach the agent. It blocks prompt injection, memory extraction and tool abuse with a hybrid detection engine (rules + machine learning + semantic similarity + LLM reasoning) and enforces least-privilege access to tools.

# Research

This work is described in a co-authored paper, currently submitted for publication.

# Limitations and next steps
New attack styles need periodic updates to the attack library and classifier.
The LLM reasoning layer adds latency to escalated requests.
Next: streaming support, a policy-as-code configuration for tool permissions, and a dashboard of blocked attacks.
